# Lit - Poetry & Literary Verses by Anbarasi U

**Live Site:** [lit.anbuu.in](https://lit.anbuu.in)

Poetry and literary verses by Anbarasi U (Anbu) - exploring themes of identity, technology, philosophy, and human experience through contemporary poetry and creative writing.

## About

Lit is a collection of poetry, literary verses, and creative writing that explores the intersection of technology, humanity, philosophy, and emotion. Topics include:

- Contemporary Poetry - Original poems exploring modern life and human experience
- Philosophical Musings - Verses that question, wonder, and reflect on existence
- Tech & Poetry - Poems at the intersection of technology and humanity
- Translations - Literary works translated across languages
- Experimental Writing - Creative explorations in form and expression
- Identity & Culture - Reflections on belonging, culture, and self

## Local Development

```bash
# Clone the repository
git clone https://github.com/anbarasiu/lit.git
cd lit

# Install dependencies
bundle install

# Run locally
bundle exec jekyll serve

# Open browser
open http://localhost:4000
```

## Writing Posts

Create a new file in `_posts/` with the format: `YYYY-MM-DD-title.md`

```markdown
---
layout: post
title: "Your Poem Title"
description: "Brief description for SEO (100-160 chars)"
---

Your poem content here...
```

## Philosophy

Poetry is not an escape from the technical world—it's a deeper engagement with it. Code and verse both seek precision, meaning, and elegance. Both are attempts to capture something true in structured form.

This blog celebrates that duality: the logical and the lyrical, the analytical and the artistic, the engineered and the organic.
